Описание проекта

О проекте

Проект автоматизации тестирования сайта Stellar Burgers направлен на проверку ключевых пользовательских сценариев, таких как регистрация, авторизация, навигация по разделам и выход из учетной записи. Все тесты выполнены с использованием Python, Selenium WebDriver и Pytest.

Цель проекта

Цель проекта — обеспечить стабильную работу критически важных функций сайта и упростить процесс регрессионного тестирования. Автоматизация позволяет быстро выявлять ошибки в процессе разработки и внедрения изменений.

Основные функции и тестируемые сценарии
	•	Регистрация: Проверка возможности регистрации новых пользователей с уникальными email-адресами.
	•	Авторизация: Тесты на вход в систему с корректными данными.
	•	Выход из системы: Проверка функциональности выхода из аккаунта.
	•	Навигация: Проверка переходов между основными разделами сайта (Конструктор, Лента заказов, Личный кабинет).
	•	Скроллинг: Проверка корректности прокрутки к различным разделам страницы (Булки, Соусы, Начинки).

Технологический стек
	•	Язык программирования: Python 3.8+
	•	Фреймворки:
	•	Selenium WebDriver — для взаимодействия с элементами веб-страниц.
	•	Pytest — для организации тестов и запуска тестовых сценариев.
	•	Браузер: Google Chrome
	•	Вспомогательные библиотеки:
	•	pytest-html — для генерации HTML-отчетов.

Структура проекта

Sprint_5/
│
├── confest.py               # Общие настройки и фикстуры для тестов
├── tests/                   # Директория с тестами
│   ├── locators.py          # Локаторы элементов страниц
│   ├── data.py              # Тестовые данные
│   ├── test_login           # Тесты авторизации
│   ├── test_registration    # Тесты регистрации
│   ├── test_logout          # Тесты выхода из системы
│   ├── test_by_pages        # Тесты навигации между страницами
│   ├── test_get_by_sections # Тесты скроллинга по разделам
│   └── __init__.py          # Указывает на то, что это Python-пакет
└── .pytest_cache            # Кэш Pytest
